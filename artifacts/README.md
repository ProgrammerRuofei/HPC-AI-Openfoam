# Presentation artifacts, not canonical measurements

Figures, slide decks, renderings and spreadsheets are derived reporting
artifacts. Their numbers must be checked against cluster-specific run records,
original solver logs and same-run correctness evidence, not cited as the sole
source of a performance claim.
