# Gadi ICX hierarchical (26 8 2), four-node comparison

The user approved one ICX 2025.3.2 and one ICX 2026.2 four-node run, in that order, after reviewing the script differences. Each is derived from its own previously successful Scotch script; the only scientific configuration change is decomposition to hierarchical (26 8 2), with order xyz and delta 0.001 inherited from the fixed case. New job names, stdout, job-keyed evidence directories, decomposition checks, and pass markers avoid overwriting Scotch evidence.

Each job requests pm78/normalsr, four Sapphire Rapids 8470Q nodes at 104 ranks per node (416 total), 760 GB RAM, 100 GB JOBFS and one hour (832 SU request ceiling). Both use OpenFOAM v2512, the fixed 65,334,765-cell occDrivAerStaticMesh, unchanged mesh and source hashes, fvSchemes, fvSolution.fixedIter, 150 SIMPLE steps, and the same four-stage preparation chain. The private Open MPI 5.0.10 archive is common. Each script pins its own prevalidated compiler/OpenFOAM runtime archives and binary hash.

This is a within-stack decomposition comparison first. The ICX 2025 template loads UCX 1.18.1 and UCC 1.4.4 modules and launches with pml ucx without an explicit collective override or library preload. The ICX 2026 template explicitly preloads site UCX 1.18.1, excludes HCOLL, and records rank binding. These differences are preserved from their previously successful Scotch runs; therefore cross-version timing cannot be attributed to compiler version alone. Loaded modules also do not prove historical effective library and collective choices. A compiler-isolated comparison requires a separately controlled environment and evidence.

For each completed job, review the original Gadi evidence files, not just extracted metrics: run.log, decomposition.txt, 10_decomposePar.log, the four preparation logs, simpleFoam.log, avg-step-time.txt, coefficient.dat, rank-host-map.txt, case-inputs.sha256, simpleFoam.ldd, and the independent PBS stdout/receipt. Record PBS exit, pass marker, four hosts at 104 ranks, hash checks, Time = 150/End, coded seconds per step, final Cd, actual SU, total and per-rank processor faces. Do not infer MPI Waitall from face counts; hierarchical PMPI rank measurements do not yet exist.
